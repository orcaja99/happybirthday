# Birthday Wishes Replica

A standalone HTML/CSS/JavaScript recreation inspired by the linked birthday-wishes demo.

## Run

No build step is required.

1. Extract the folder.
2. Open `index.html` in a browser.

For best results, serve it locally:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Customize

- Replace the photo placeholder in `index.html` with an `<img>` if you have a photo.
- Change the recipient/name in the footer and special-gift heading.
- Edit the three gift messages in `script.js`.
- Edit colors and typography in `style.css`.

The melody is generated with the Web Audio API, so there is no external audio file.
